# ASDI Chatroom Android v3.41 - Logout and Footer

Requires ASDI Ticketing server v3.34.

- Native footer: ASDI Chatroom v3.41 / Created by dannyboi620 / Log out
- Tap footer to confirm server-side logout; clears WebView cookies after successful logout
- Preserves v3.40 full-width chat layout and Android notification behavior
- Logout uses POST mobile_logout.php; on error the app does not pretend the user is logged out

Upload project files to GitHub and run Actions to compile app-debug.apk.
This is a source project, not a compiled APK.
